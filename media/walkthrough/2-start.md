# Start the FCC server

The extension can run `fcc-server` for you (output goes to the **Free Claude Code** output channel) or in a VS Code terminal (`fcc.server.runIn`).

On Windows and macOS you can instead open **Free Claude Code** from the desktop/Start menu or Applications folder — the extension detects an already-running server automatically (default `http://127.0.0.1:8082`).

Linux: `fcc-server` (keep its terminal open).
