# Install Free Claude Code

FCC is a local proxy that lets coding agents (Claude Code, Codex, Pi, OpenCode, Cline, Hermes, DeepSeek Harness, Grok Build, Muse Code, Aider) use free, paid or local models.

The button runs the **official installer** from the FCC repository in a terminal, after you confirm. When prompted by the installer, choose at least one coding agent and optionally enable RTK + Headroom token optimization.

Prefer to do it by hand?

- macOS/Linux: `curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh`
- Windows PowerShell: `& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))`

*This extension is unofficial and not affiliated with the FCC project or Anthropic.*
