# Launch a coding agent

Pick an agent from the **Coding Agents** view or run **FCC: Launch Coding Agent…**:

`fcc-claude` · `fcc-codex` · `fcc-pi` · `fcc-opencode` · `fcc-cline` · `fcc-hermes` · `fcc-dsh` · `fcc-grok` · `fcc-muse` · `fcc-aider`

FCC launchers start the server automatically and read the current Admin UI settings. Use the agent's own model picker to choose from the models FCC exposes.

Using Claude Code or Codex inside VS Code? See the **Integrations** view.
